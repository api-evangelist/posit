# Posit

> [Posit](https://posit.co) (formerly RStudio) provides open-source and enterprise-ready professional software for data science teams using R and Python.

## Core Products
- [Posit Team](https://posit.co/products/enterprise/team/): A bundle of Workbench, Connect, and Package Manager for end-to-end data science.
- [Posit Workbench](https://posit.co/products/enterprise/workbench/): Centralized development environment supporting RStudio IDE, VS Code, Jupyter, and Positron.
- [Posit Connect](https://posit.co/products/enterprise/connect/): A publishing platform for Shiny apps, Quarto docs, APIs (Plumber/FastAPI), and more.
- [Posit Package Manager](https://posit.co/products/enterprise/package-manager/): Repository management for secure, reproducible R and Python packages.
- [Posit Cloud](https://posit.cloud/): A cloud-based version of Posit’s IDEs for easy sharing and teaching.
- [Positron](https://positron.posit.co/): A next-generation, extensible data science IDE built by Posit.

## Open Source
- [Tidyverse](https://www.tidyverse.org/): A collection of R packages designed for data science.
- [Quarto](https://quarto.org/): An open-source scientific and technical publishing system.
- [Shiny](https://shiny.posit.co/): A framework for building interactive web applications with R and Python.
- [tidymodels](https://www.tidymodels.org/): A framework for modeling and machine learning using tidyverse principles.
