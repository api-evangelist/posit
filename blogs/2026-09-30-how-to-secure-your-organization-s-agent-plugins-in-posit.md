How to secure your organization's agent plugins in Posit Package Manager Posit Package Manager now secures your agent plugins. Your data teams can adopt AI agents sooner, because plugins come from a repository your administrators curate, the same way they already curate R and Python packages. Host them in a dedicated plugins repository that pulls from both public and private sources and serves them, optionally pinned to a point in time, as one governed marketplace.
