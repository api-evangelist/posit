We are absolutely thrilled to announce the release of ggsql 0.5.0, the first beta release of ggsql since the initial release back in April. While this release brings a lot of core improvements, the beta label marks the maturity of the project more than any specific feature in this release. That being said, the features included are exciting so let’s tell you all about them.
