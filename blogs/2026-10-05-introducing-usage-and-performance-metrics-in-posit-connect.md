Introducing usage and performance metrics in Posit Connect Cloud Your content on Connect Cloud is worth more when it runs well and people actually use it. With new usage metrics, you can now see how much compute it consumes. You can also see whether the CPU and memory you have allotted meets current demand, or if fine-tuning the limits make sense.
