I’m thrilled to share the latest querychat release for both R (v0.4.0) and Python (v0.9.0). Grab the latest from CRAN or PyPI: R Python install.packages ( "querychat" ) pip install -U querychat This release adds several headline features, including support for multiple tables, data-dict.yml , a full-page chat layout, support for pins, and a new /handoff command. It also builds on shinychat’s recent momentum .
