I’m as amped as Ella Langley’s Gibson to share that vitals 0.4.0 is now on CRAN! vitals implements a large language model evaluation toolkit for R, and this release contains several exciting features. To install the newest release, run the following in R: install.packages ( "vitals" ) The package includes two new helpers, claude_code() and codex() , which allow you to compare your own ellmer-built agents with leading coding agents.
